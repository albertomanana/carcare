# Car Care — documentación inicial del proyecto

Esta carpeta contiene el contexto de producto, alcance funcional, dirección visual, arquitectura candidata, estrategia de desarrollo y documentación inicial para trabajar con Claude Code.

## Archivos
- `01_Vision_y_producto.md`: visión, problema, propuesta de valor, usuarios y diferenciación.
- `02_Requisitos_y_modulos.md`: módulos, funcionalidades y criterios iniciales de aceptación.
- `03_Diseno_UI_UX.md`: dirección visual, experiencia de usuario y sistema de diseño.
- `04_Arquitectura_y_datos.md`: arquitectura candidata, modelo de datos inicial y seguridad.
- `05_Roadmap_TFG_y_producto.md`: fases, prioridades, validación comercial y entregables académicos.
- `06_Instrucciones_Claude_Code.md`: reglas de trabajo y primera tarea para Claude.
- `07_Mensaje_objetivo_Claude.txt`: mensaje listo para pegar en Claude, de menos de 8.000 caracteres.

## Importante
Este documento es una base de trabajo, no una especificación cerrada. Antes de implementar, Claude debe inspeccionar el repositorio existente, las instrucciones oficiales del TFG de Ilerna y las tecnologías que exige la evaluación. No debe reemplazar ni migrar código sin justificarlo y pedir aprobación.

Los nombres, módulos y tecnologías aquí propuestos son iniciales. Las decisiones definitivas deben basarse en el estado real del proyecto, las exigencias académicas y pruebas con usuarios.
